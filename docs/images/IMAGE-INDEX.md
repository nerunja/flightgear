## Image Guidelines

### Adding Images to Documentation

When adding images to markdown documents, use this format:

```markdown
![Descriptive Alt Text](images/image-filename.png)
*Caption explaining what the image shows*
```

**Example**:
```markdown
![VOR Indicator](images/vor-indicator-obs-knob.png)
*VOR indicator showing CDI needle, TO/FROM flag, and OBS knob*
```

### Image Naming Convention

Images follow this naming pattern:
- **Descriptive name**: `vor-indicator-obs-knob.png`
- **Lowercase with hyphens**: for URL compatibility
- **Clear purpose**: name indicates what image shows
