## Introduction

FlightGear offers stunning scenery around the world, from iconic airports to famous landmarks. This guide highlights the most interesting and scenic locations to explore.

**Note**: Many locations require scenery data to be downloaded. FlightGear will automatically download scenery when you visit a location, or you can pre-download using TerraSync.

## Top Scenic Airports

### United States

#### KSFO - San Francisco International Airport
**Location**: California, USA
**Coordinates**: 37.6213° N, 122.3790° W
**Highlights**:
- Views of San Francisco Bay
- Golden Gate Bridge visible from departure/approach
- Multiple parallel runways for practice
- Complex airspace

**Recommended Flight**:
```bash
--aircraft=c172p --airport=KSFO --runway=28R --timeofday=afternoon
```

#### KLGA - LaGuardia Airport, New York
**Location**: New York, USA
**Highlights**:
- Manhattan skyline views
- Statue of Liberty (island visible from Empire State Building area)
- Look for Empire State Building (has tower antenna at top)
- Fly past Empire State Building and locate Statue of Liberty island

**Navigation Tip**:
- Statue of Liberty is on an island, viewable from high-rise buildings
- Empire State Building is distinctive with its antenna tower
- Explore the area for all the skyscrapers

**Recommended Flight**:
```bash
--aircraft=c172p --airport=KLGA --timeofday=morning
```

#### KLAS - McCarran International Airport, Las Vegas
**Location**: Nevada, USA
**Highlights**:
- Las Vegas Strip
- Desert landscape
- Famous casinos visible
- Night flights are spectacular

**Recommended Flight**:
```bash
--aircraft=c172p --airport=KLAS --timeofday=evening
```

#### KHAF - Half Moon Bay Airport
**Location**: California, USA
**Highlights**:
- Coastal scenery

- Close to San Francisco Bay Area

**Recommended Flight**:

**Location**: EGLC area, London

1. Start at London City Airport (EGLC), runway 34

## Tips for Sightseeing Flights

### Planning Your Sightseeing Flight

1. **Choose the Right Time of Day**
   - **Afternoon**: Best lighting for most locations
   - **Morning**: Softer light, less haze
   - **Evening/Dusk**: Dramatic lighting, city lights coming on
   - **Night**: See illuminated landmarks and cities

2. **Aircraft Selection**
   - **Cessna 172p**: Excellent for sightseeing (good visibility, slow speed)
   - **Helicopters**: Best maneuverability for landmarks
   - **Slower aircraft**: Better for detailed observation

3. **Flight Planning**
   - **Low and slow**: 1000-2000 ft AGL, 80-100 knots
   - **Circle landmarks**: Use gentle 20° bank turns
   - **Use autopilot heading hold**: Easier to look around

### In-Flight Viewing

1. **Camera Controls**
   - **v** - Cycle through views
   - **Ctrl + Arrow Keys** - Look around
   - **Right Mouse + Drag** - Pan view
   - **x/X** - Zoom in/out

2. **Best Viewing Mode**
   - **Helicopter View** (press v multiple times): Best for landmarks
   - **Chase View**: Good for seeing aircraft with scenery
   - **Cockpit View**: Most immersive

3. **Enable Map**
   - **Ctrl + M**: Show map overlay
   - Helps locate landmarks
   - Shows your position relative to POIs

4. **Use Marker Pins**
   - **View → View Options → Show Marker Pins**: Enables beam of light at each airport
   - Helps locate destinations from distance

### Changing Airport Mid-Flight

Don't want to exit and restart? Change airports on the fly:
1. Press **F10** (Menu)
2. **Location → Select Airport**
3. Choose from alphabetical list
4. Aircraft repositions immediately

**Airport Lists**:
- By ICAO code: https://en.wikipedia.org/wiki/List_of_airports_by_ICAO_code:_K

### Screenshot and Recording

1. **Take Screenshots** (varies by OS):
   - Check FlightGear documentation for screenshot key
   - Usually saved to FlightGear data directory

2. **Record Flight**
   - Use external screen recording software
   - Disable HUD for cleaner videos (press **h**)

## Scenery Installation

### Automatic Scenery Download (TerraSync)

FlightGear automatically downloads scenery as you fly. However, for better experience:

1. **Pre-download Scenery**:
   - Enable TerraSync in launcher
   - Fly to area once
   - Scenery caches for future use

### Manual Scenery Installation

Some scenic locations may require manual scenery installation:

1. **Download Scenery Files**:
   - FlightGear Scenery Database
   - Third-party scenery providers

2. **Install Location** (Linux):
   ```
   /home/[username]/.fgfs/
   ```

3. **Create Tar Archives** from ZIP files:
   ```bash
   find . -iname "*.zip" -exec tar -cvf {}.tar {} \;
   ```

4. **Add to FlightGear**:
   - Settings → Additional Scenery Folders
   - Point to downloaded scenery location
