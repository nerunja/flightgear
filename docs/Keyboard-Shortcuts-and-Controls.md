## Essential Controls

### Mouse Control Modes
- **Tab** - Toggle mouse control mode (+ cursor appears)
- **Right Mouse Button** - Click to change mouse to control mode
- **Left Mouse Button (held)** - Control rudder instead of yoke when in mouse mode
- **Right Mouse Button + Drag** - Look around (pan view) without leaving current mode

### Emergency Controls
- **Ctrl + U** - Increase altitude by 1000 ft (emergency/cheat code)

---

## View Controls

### Basic View Commands
- **v** - Cycle through different views (cockpit, chase, tower, etc.)
- **V (Shift + v)** - Switch to Full Panel view (IFR Training view)
- **Ctrl + v** - Quickly return to cockpit view from any other mode
- **c** - Toggle show/hide cockpit
- **P (Capital P)** - View FULL PANEL (only panels in full view, no outside)
- **p (lowercase)** - Pause the simulator

### Cockpit View Adjustments
- **x** - Zoom in cockpit view
- **X (Shift + x)** - Zoom out cockpit view
- **Ctrl + X** - Reset cockpit view (resets FOV to default 55 degrees)
- **Ctrl + Right Click + Drag** - Adjust cockpit view position to fine-tune visibility

### Seat Position and View Angle
- **Alt + PgUp / PgDn** - Adjust seat height
- **Ctrl + Drag Right Mouse** - Adjust seat height (alternative method)
- **Drag Right Mouse** (without Ctrl) - Adjust view angle without changing seat height

### Looking Around
- **Ctrl + Arrow Keys** - Look around in different directions
- **Shift + Hold** - View around while flying (look around without changing flight controls)

### Helicopter/External View
- **v** - Press multiple times to reach Helicopter View
- **Right Mouse + Drag** - Pan to view around the airport (in mouse control mode)

## Flight Controls

### Rudder (Tail - Side-to-Side Movement)
- **Numpad 0** - Turn left (rudder left)
- **Numpad Enter** - Turn right (rudder right)
- **Numpad 5** - Reset rudder to center (fly straight)

**Note**:
- Use rudder primarily **after** nose wheel lifts off (above 40 knots)
- At airspeeds above 40 knots, the rudder has enough airflow to steer effectively
- At speeds below 40 knots, use wheel brakes (comma/period keys)

### Ailerons (Wing Flaps - Roll Control)
- **Numpad 4** - Roll left (aileron left)
- **Numpad 6** - Roll right (aileron right)
- **Numpad 5** - Reset ailerons to neutral position

**Note**: Requires flaps to be deployed with [ or ] keys for effect

### Mouse Yoke Control
When in mouse control mode (Tab):
- **Move Mouse** - Control pitch (up/down) and roll (left/right)
- **Hold Left Mouse** - Switch to rudder control (for straight takeoff)

**Important Speeds**:
- **Below 40 knots**: Use left mouse button for rudder control (nose wheel steering)
- **Above 40 knots**: Release left mouse and use mouse for yoke control

## Throttle and Engine Controls

### Throttle
- **Page Up** - Increase throttle
- **Page Down** - Decrease throttle
- **Shift + A** - Reduce speed by half (useful for pausing without stopping engine)

**Target RPM**:
- **Ground/Taxi**: 1000 RPM
- **Landing Approach**: ~1500 RPM

### Mixture Control
- **m (lowercase)** - Richer mixture (more fuel, less air - for powerful engine)
- **M (uppercase)** - Leaner mixture (more air, less fuel - for fuel efficiency)

**Usage**:
- **Takeoff and Landing**: Use **m** for richer mixture (more power)
- **High Altitude**: Use **M** for leaner mixture (reduce fuel usage)
- **Test**: Press **M** repeatedly - propeller will stop when mixture is too lean

## Flaps and Trim

### Flaps
- **]** - Extend flaps one step (increase drag and lift)
- **[** - Retract flaps one step

**Flap Usage**:
- **Below 115 knots**: Apply first step of flaps
- **~1000 ft**: Apply second step
- **~500 ft**: Apply final step (full flaps for landing)
- **Landing**: Press **]** 3 times for full flaps, target speed ~65 knots

### Elevator Trim
- **Numpad 1** - Nose pitch up (trim up)
- **Numpad 7** - Nose pitch down (trim down)

**Note**: Need to hold for a considerable time to see effect. Check the horizontal tab below rudder for trim position.

## Brakes and Steering

### Brakes
- **B (uppercase)** - Toggle parking brake
- **b (lowercase)** - Apply both wheel brakes (press repeatedly to halt)
- **,** (comma) - Apply left wheel brake (causes left turn when taxiing)
- **.** (period) - Apply right wheel brake (causes right turn when taxiing)

**Brake Usage**:
- **Taxiing slowly**: Use comma (,) and period (.) for directional control
- **Below 30 knots**: Use **b** to slow down further
- **Above 40 knots**: Use rudder (Numpad 0/Enter) for directional control

## Autopilot Controls

**Note**: In Cessna 172p, Menu Autopilot is disabled. Use the instrument panel HDG button instead.

### Autopilot Keys
- **Backspace** - Toggle autopilot on/off
- **Ctrl + A** - Toggle altitude lock
- **Ctrl + G** - Toggle glide slope lock (NAV 1)
- **Ctrl + H** - Toggle heading hold
- **Ctrl + N** - Toggle NAV 1 lock
- **Ctrl + S** - Toggle autothrottle
- **Ctrl + T** - Toggle terrain follow (AGL) lock
- **Ctrl + U** - Add 1000 ft to altitude (emergency)
- **F6** - Toggle autopilot heading mode
- **F11** - Open autopilot altitude dialog

### Using HDG (Heading) Autopilot
1. Set desired heading using the HDG bug knob in Heading Indicator
2. Click **AP** button in autopilot instrument panel
3. Click **HDG** button to enable heading hold
4. Aircraft will automatically turn to the set heading
5. Turning HDG bug knob will change heading even while autopilot is active

## Custom Key Bindings

### How to Customize Keyboard Bindings
Edit the keyboard configuration file:
- **File**: `/usr/share/games/flightgear/keyboard.xml`
- **Documentation**: http://wiki.flightgear.org/Howto:Reassign_keyboard_bindings
- **Reference**: http://www.flightgear.org/Docs/FGShortRef.html

### Example: Use INSERT Instead of Page Up for Throttle

Add this to `keyboard.xml`:

```xml
<key n="364">
    <name>Insert</name>
    <desc>Increase throttle or autopilot autothrottle</desc>
    <repeatable type="bool">true</repeatable>
    <binding>
        <command>nasal</command>
        <script>
            controls.incThrottle(0.01, 1.0)
        </script>
    </binding>
    <mod-shift>
        <desc>Look front right</desc>
        <binding>
            <command>property-assign</command>
            <property>/sim/current-view/goal-heading-offset-deg</property>
            <property>/sim/view/config/front-right-direction-deg</property>
        </binding>
    </mod-shift>
</key>
```

### Example: Use DELETE Instead of Page Down for Throttle

Add this to `keyboard.xml`:

```xml
<key n="127">
    <name>Delete</name>
    <desc>Decrease throttle or autopilot autothrottle</desc>
    <repeatable type="bool">true</repeatable>
    <binding>
        <command>nasal</command>
        <script>
            controls.incThrottle(-0.01, -1.0)
        </script>
    </binding>
    <mod-shift>
        <desc>Look back right</desc>
        <binding>
            <command>property-assign</command>
            <property>/sim/current-view/goal-heading-offset-deg</property>
            <property>/sim/view/config/back-right-direction-deg</property>
        </binding>
    </mod-shift>
</key>
```

## Quick Reference Card

### Takeoff Sequence
1. **PgUp** - Throttle to 1000 RPM
2. **Tab** - Enable mouse control
3. **Hold Left Mouse** - Control rudder for straight takeoff
4. **40 knots** - Release left mouse, pull back slightly (nose up)
5. **55 knots** - Aircraft lifts off
6. **70-75 knots** - Target climb speed

### Landing Sequence
1. **1500 RPM** - Reduce power at 1500 ft
2. **]** - Apply flaps at 115 knots (first step)
3. **]** - Apply more flaps at 1000 ft
4. **]** - Full flaps at 500 ft
5. **65-70 knots** - Target landing speed
6. **55 knots** - Touchdown speed
7. **40 knots** - Lower nose wheel
8. **30 knots** - Apply brakes (b)

### Turning at 20° Bank
- **120 seconds** = 360° turn
- **60 seconds** = 180° turn
- This timing works regardless of speed in Cessna 172p

## Tips and Tricks

1. **Horizon Reference**: Note the horizon line level relative to aircraft nose while on ground as a reference for knowing if the flight is level while flying
2. **Rudder vs Ailerons**: Rudder controls yaw (rotation around vertical axis), ailerons control roll (rotation around longitudinal axis) - they're complementary
3. **Station Passage**: When flying over a VOR station, instruments become very sensitive
4. **Seat Position**: Adjust seat height (Alt + PgUp/PgDn) for better instrument visibility
5. **View Shortcuts**: Use Ctrl + v to quickly return to cockpit view from any other view
